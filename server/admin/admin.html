Admin is switched off

This server has no admin token, so nothing can be changed from here. The app can still play the music and ads it already holds.

To turn admin on, set WS4K_TOKEN to a long random secret and restart the server. For example:

WS4K_TOKEN=$(openssl rand -hex 32) node server.mjs

Docker: set WS4K_TOKEN in a .env file beside docker-compose.yml, or pass -e WS4K_TOKEN=… to docker run.

systemd: put WS4K_TOKEN=… in /etc/weatherfeels-companion.env, then sudo systemctl restart weatherfeels-companion.

Then reload this page and sign in with that token. Keep it secret: it lets anyone who has it change what the app shows.

                  Static hosting

                  The app reads ads from any web server, not only this one. To publish them on a static host, save the public ads.json (enabled items only) to the root of the site, and copy this server's images/ and clips/ folders into an ads/ folder beside it.
